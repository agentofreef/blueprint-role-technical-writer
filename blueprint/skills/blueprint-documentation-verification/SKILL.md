# 文档示例核验；在对应验证或交付场景下使用。

沿读者路径验证安装、配置、调用、输出和故障恢复，核对链接、参数名和版本。命令检查语法和副作用；可安全运行的示例在隔离目录验证。
对错误说明提供真实错误码、触发原因和下一步，移除与当前版本不符的步骤。记录未验证部分，避免复制旧文档造成虚假能力承诺。

执行前调用平台提供的 ensure_role_environment，核对本节点真实执行环境。缺项先准备并复核；安装失败或能力不兼容应返回具体证据，不把注册视为已加载。遵守平台工作区、权限和交付协议。
